Não usa o Cloud Code se você não instalou esses cinco plugins. O primeiro é o OmniHout, que te dá o uso praticamente ilimitado, conectando o Cloud Cone e a mais de 200 provedores de API de A, pra usar de graça. Aí o segundo que é o Limite estoura, ele troca sozinho pro próximo e melhor modelo. Dá até 1,6 bilhão de tokens de graça, todo mês. O segundo é o Cloud Main. Ele dá memória para o Cloud entre todas as sessões. Então ele começa a lembrar dos seus projetos. Arquivos e você nunca mais explica nada. O terceiro é o Hadron, ele fica entre você e o modelo e só deixa passar o que importa de verdade, comprimindo e jogando fora todo o resto. Mesmo resultado, com muito menos shockens. O quarto é o Cloud Setup, que é o plugin oficial da Antrop, que escaneia a sua base de código inteira e recomenda os melhores hooks, skills, subagentes e até servidores MCP para o seu projeto. E tira. Todo o entulho e o ruído do caminho. E por último, o Test Observer. Ele observa como você trabalha, aprende seu estilo e vai melhorando as suas skins sozinho, de forma totalmente automática. Se você quer testar, comenta, Claudio aqui embaixo e me segue, que eu te mando passo a passo completo.
