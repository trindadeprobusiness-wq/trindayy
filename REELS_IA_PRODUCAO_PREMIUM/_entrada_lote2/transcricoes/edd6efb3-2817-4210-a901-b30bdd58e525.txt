Agora dá pra rodar o Call of Code de graça com os quase limitados. Alguém no GitHub acabou de criar uma ferramenta que te dá mais de 7 bilhões de token de A de graça todo santo mês. Isso inclui modelos como ChatBT, Gemini, GLM, Kimi, Groc, Mistral, Cloud Code e muito mais. Ele se chama FLLM API e conecta com o seu cloud code a mais 600 modelos de A gratuito, tudo numa configuração bem simples. E aí, no momento que seu limite do Call of Code acaba, ele te troca automaticamente. Basicamente para o próximo modelo, a próxima sessão sempre continuar rodando e ainda te deixa uma nota pra trás durante a troca. Pro novo modelo que chegar já saber o contexto que foi feito ali.
