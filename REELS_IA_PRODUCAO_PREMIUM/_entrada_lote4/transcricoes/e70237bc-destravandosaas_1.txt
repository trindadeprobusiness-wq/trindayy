Você pede pro Cloud, faz uma app de agendamento. Ele faz. Lindo. E ele só existe no seu computador. Desligou o computador, o app sumiu. Então você pede pro Clude colocar ele num computador que fica ligado o dia inteiro, na internet. Esse é o servidor. Mas, pra entrar, o cliente precisa digitar um número enorme. Então você compra um nome fácil, que é a Ponta para o servidor. Esse é o domínio. Mas o cliente marca um horário, recarrega a página e o horário sumiu. Então você pede para o Cloud guardar tudo num lugar que não apaga. Esse é o banco de dados. Mas agora qualquer pessoa entra e mexe na agenda. Então cada cliente cria uma conta, com e-mail e senha. Esse é o login. Mas o cliente A Entra e vê a agenda do cliente B. Então você pede pro Cloud marcar o dono de cada horário e cada um só vê o que é seu. Essas são as permissões. Mas a tela fala direto com o banco. Quem descobrir o caminho apaga tudo. Então você põe uma peça no meio que confere cada pedido antes de deixar passar. Essa é a API. Agora você quer cobrar. Mas guardar o cartão do cliente é proibido. Então você entrega o cartão para uma empresa que só faz isso. Esse é o Gateway de Pagamento. Mas o pagamento acontece lá fora. Como o seu app sabe que o cliente pagou? O Gateway manda um aviso pro seu servidor. Esse é o Webhook. Mas cobrar todo mês na mão não dá. Então você pede pro Clo de cobrar sozinho. Todo mês no mesmo dia. Essa é a assinatura. Mas o cliente esqueceu a senha e o cartão dele venceu. Ninguém avisa ninguém. Então o seu app manda e-mail sozinho. Esse é o e-mail transacional. Mas a chave do pagamento está escrita no código. Subiu pro GitHub e um robô achou em minutos. Então você guarda as chaves fora do código, num cofre do servidor. Essas são as variáveis de ambiente. Mas o servidor caiu às três da manhã e você só descobriu quando o cliente reclamou. Então você coloca um alarme que te avisa no celular. Esse é o monitoramento. Mas um dia, sem querer, você apaga o banco inteiro. Então, toda noite uma cópia vai pra outro lugar. Esse é o backup. Parabéns! Destruir um SaS! Agora comenta qual dessas peças você quer ver desmontada.
