Você pede para o Clod, faz um app de agendamento. Ele faz, lindo. E ele só existe no seu computador. Desligou o computador, o app sumiu. Então você pede para o Clod colocar ele num computador que fica ligado o dia inteiro na internet. Esse é o servidor. Mas para entrar, o cliente precisa digitar um número enorme. Então você compra um nome fácil que aponta para o servidor. Esse é o domínio. Mas o cliente marca um horário, recarrega a página e o horário sumiu. Então você pede para o Cloud guardar tudo num lugar que não apaga. Esse é o banco de dados. Mas agora qualquer pessoa entra e mexe na agenda. Então cada cliente cria uma conta com e-mail e senha. Esse é o login. Mas o cliente A entra e vê a agenda do cliente B. Então você pede para o Clod marcar o dono de cada horário e cada um só vê o que é seu. Essas são as permissões. Mas a tela fala direto com o banco e quem descobrir o caminho apaga tudo. Então você põe uma peça no meio que confere cada pedido antes de deixar passar. Essa é a API. Agora você quer cobrar, mas guardar o cartão do cliente é Proibido. Então você entrega o cartão para uma empresa que só faz isso. Esse é o gateway de pagamento. Mas o pagamento acontece lá fora. Então, como o seu app sabe que o cliente pagou? O Gateway manda um aviso para o seu servidor. Esse é o webhook. Mas cobrar todo mês na mão não dá. Então você pede para o Cloud cobrar sozinho, todo mês, no mesmo dia. Essa é a assinatura. Mas o cliente esqueceu a senha e o cartão dele venceu, e ninguém avisa ninguém. Então o seu app manda e-mail sozinho. Esse é o e-mail transacional. Mas a chave do pagamento está escrita no código. Subiu para o GitHub e um robô achou em minutos. Então você guarda as chaves fora do código num cofre do servidor. Essas são as variáveis de ambiente. Mas o servidor caiu às 3 da manhã e você só descobriu quando o cliente reclamou. Então você coloca um alarme que te avisa no celular. Esse é o monitoramento. Mas um dia, sem querer, você apaga o banco inteiro. Então toda noite uma cópia vai para outro lugar. Esse é o backup. Parabéns! Você construiu um SaS. Agora comenta. Qual dessas peças você quer ver desmontada?
