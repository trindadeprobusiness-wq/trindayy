## 02 · XTOOL + CLAUDE CODE
Criar app de iPhone sem depender de um Mac? 📱

O xtool é um projeto de código aberto que funciona como alternativa multiplataforma a ferramentas do Xcode: Swift e SwiftUI no Windows e no Linux, com compilação e instalação em dispositivos compatíveis (respeitando os requisitos da Apple).

Junta isso com o Claude Code e você acelera boa parte do desenvolvimento com comandos em linguagem natural.
